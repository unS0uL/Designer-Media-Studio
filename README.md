# Screenshots

This orphan branch holds only the PNG screenshots embedded in the `main`
branch's `README.md` via the `raw.githubusercontent.com` CDN, kept separate
so they never bloat the source history.

- `dashboard.png` -- main dashboard
- `compare.png` -- before/after split comparison with the live quality slider
- `settings.png` -- per-format settings with enable/disable toggles

Captured at 1440x900 via Playwright against the running dev server, on a
synthetic demo banner (no third-party or brand images).
